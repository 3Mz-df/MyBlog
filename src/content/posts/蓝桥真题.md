17届第一题填空：## 拼接数 取余

第 1 天，喂食器吐出 1 颗猫粮；
第 2 天，喂食器吐出 12 颗猫粮（将 1 和 2 拼在一起）；
第3 天，喂食器吐出 123 颗猫粮；
……
如果某天吐出的猫粮总数，能够被这 26 只猫完全平分（即每只猫分到的颗粒数一模一样），它们就会相安无事，这一天被称为“和平干饭日”。如果不能被完全平分，它们就会为了抢夺残粮而大打出手。

现在，喂食器的运行计划已经设定了整整 2026 天。请你帮忧心忡忡的小蓝算一算，在这 2026 天里，总共有多少天是“和平干饭日”？
----------------------------------------------------------------

解题思路：

要算的是`123456 % 26` 。这件事从头到尾没变，`rem` 存的就一直是 当天那个拼接大数除以 26 的余数 。
变的只是 算法怎么拿到这个余数 ：不把 123456 整个造出来，而是拆开算。

第二天：1 ‘+’2（一位数） --> 12 {所以x1}
第十一天：一个九位数 '+' 11(两位数) {所以x2}
后面同理 几位数就乘几 算出2026天的时候是几位数
1～9     ：9 个数 × 1 位 = 9 位
10～99   ：90 个数 × 2 位 = 180 位
100～999 ：900 个数 × 3 位 = 2700 位
1000～2026：1027 个数 × 4 位 = 4108 位
总共                               6997 位

取余 除掉26余数为零的那天算入计数器count++
12345 = 1234 × 10 + 5
同余：
12345 % 26
= (1234 × 10 + 5) % 26
= (12 × 10 + 5) % 26        ← 把 1234 换成它的余数 12
= 125 % 26
= 21

拼接数：
S_3 = 123      接上 4  →  1234
                          123 × 10 + 4
                   ↑ 因为 4 只有 1 位数，所以旧数乘 10

S_9 = 123456789    接上 10  →  12345678910
                                123456789 × 100 + 10
                          ↑ 因为 10 有 2 位数，所以旧数乘 100

S_n = S_{n-1} × 10^（n 的位数） + n

rem_n = ( rem_{n-1} × (10^len % 26) + n ) % 26

rem = (rem * pow10[len] + n) % 26;

----------------------------------------------------------------

源码：

public class Main {
    public static void main(String[] args) {
        int[] pow10 = {1, 10, 22, 12, 16};   // 第 5 步的表 
        int rem = 0;                          // 第 2 步：只存余数
        int ans = 0;

        for (int n = 1; n <= 2026; n++) {
            int len = String.valueOf(n).length();      // 第 3 步：n 的位数
            rem = (rem * pow10[len] + n) % 26;         // 第 4 步：递推
            if (rem == 0) ans++;                       // 余 0 就是干饭日
        }
        
        System.out.println(ans);   // 76
    }
}

## 暴力解法就是：真的把完整数字拼出来，每天判断一次能不能被 26 整除。
import java.math.BigInteger;

public class Main {
  public static void main(String[] args) {
    StringBuilder s = new StringBuilder();
    BigInteger divisor = BigInteger.valueOf(26);
    int ans = 0;

    for (int n = 1; n <= 2026; n++) {
      s.append(n);

      BigInteger number = new BigInteger(s.toString());

      if(number.mod(divisor).equals(BigInteger.ZERO)){
        ans ++;
      }
    }
    System.out.print(ans);
  }
}

tips：
- StringBuilder 用于拼接字符串
- BigInteger 用于表示大整数
- mod() 方法用于取余
- equals() 方法用于判断是否等于

## 整体流程
- 定义一个 StringBuilder 用于放拼接字符串 变量s
- 用BigInteger构造一个除数26 这里注意BigInteger没有提供接受一个普通整数的构造方法，所以要使用
   valueOf()方法去让方法返回对象divisor 这里就不用new了，因为不是构造方法
- 定义一个 int 用于记录符合条件的日子
- 从 1 开始遍历到 2026
- s.append(n);拼接当前的天数，存在StringBuilder里
- s.toString()取出字符串，转换为大整数BigInteger类型的number里存着
- 判断当前拼接出来的大整数是否能被 26 整除
- 如果能，ans++
- 输出 ans

17届第二题填空： 选两个整数，和是完全平方数的个数
public class Main {
    public static void main(String[] args) {
        long A = 20269876543210L;
        long B = 20260123456789L;
        long MOD = 998244353L;
        long ans = 0;

        for (long k = 0; k * k <= A + B; k++) {
            long sum = k * k;

            long left = Math.max(0, sum - B);
            long right = Math.min(A, sum);

            if (left <= right) {
                long count = right - left + 1;
                ans = (ans + count) % MOD;
            }
        }

        System.out.println(ans);
    }
}

这里注意sum不是绝对等于A+B，而是等于A+B的范围内且一定是完全平方数
例如 A＝10、B＝7，最大和是 17，因此只需要考虑：
sum = 0、1、4、9、16

从左到右一共多少个数（包括两端）
sum=右加左（已定义合法情况 即sum在A+B的范围内且一定是完全平方数）
右减左加上一个1=构成sum的组合个数

总结：
先假定两个小一点的数弄清逻辑
A=10 B=7 （AB只是最大值（上限） 组成一个sum的实际的数是ab）
那A就在0-10之间 B就在0-7之间
所以sum就在0-17之间
要满足完全平方数
sum=0、1、4、9、16 sum就有这几种可能
然后取a或者b的可选范围就行了（因为ab互补成sum）
左取最大 （0，sum-B）保下限 a+b=sum可能比B小，所以要取最大
右取最小 （A，sum）保上限 a+b=sum可能比A大，所以要取最小
tips：sum值是先出的 a或b左右端点应该看sum来决定。假如sum取到16，那么a左右端点就分别是9，10，再10-9+1=2 一共2种方案。b的话就是 6，7，再7-6+1=2 也是一共2种方案
最终要求（a，b）组合数
这里取的上下限就是a的可选范围
b的可选范围就是左（0，sum-A） 右（B，sum）
每次拿到正确的sum计算完后就用count记录下方案数（右减左加上一个1）
再用ans存储下所有sum的方案数
最后按题目要求取模
