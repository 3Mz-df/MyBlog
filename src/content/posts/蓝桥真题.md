17届第一题填空：

第 1 天，喂食器吐出 1 颗猫粮；
第 2 天，喂食器吐出 12 颗猫粮（将 1 和 2 拼在一起）；
第3 天，喂食器吐出 123 颗猫粮；
……
如果某天吐出的猫粮总数，能够被这 26 只猫完全平分（即每只猫分到的颗粒数一模一样），它们就会相安无事，这一天被称为“和平干饭日”。如果不能被完全平分，它们就会为了抢夺残粮而大打出手。

现在，喂食器的运行计划已经设定了整整 2026 天。请你帮忧心忡忡的小蓝算一算，在这 2026 天里，总共有多少天是“和平干饭日”？
----------------------------------------------------------------

解题思路：

第二天：1 ‘+’2（一位数） --> 12 {所以x1}
第十一天：一个九位数 '+' 11(两位数) {所以x2}
后面同理 几位数就乘几 算出2026天的时候是几位数
1～9     ：9 个数 × 1 位 = 9 位
10～99   ：90 个数 × 2 位 = 180 位
100～999 ：900 个数 × 3 位 = 2700 位
1000～2026：1027 个数 × 4 位 = 4108 位
总共                               6997 位

取余 除掉26余数为零的那天算入计数器count++
12345 = 1234 × 10 + 5
同余：
12345 % 26
= (1234 × 10 + 5) % 26
= (12 × 10 + 5) % 26        ← 把 1234 换成它的余数 12
= 125 % 26
= 21

拼接数：
S_3 = 123      接上 4  →  1234
                          123 × 10 + 4
                   ↑ 因为 4 只有 1 位数，所以旧数乘 10

S_9 = 123456789    接上 10  →  12345678910
                                123456789 × 100 + 10
                          ↑ 因为 10 有 2 位数，所以旧数乘 100

S_n = S_{n-1} × 10^（n 的位数） + n

rem_n = ( rem_{n-1} × (10^len % 26) + n ) % 26

rem = (rem * pow10[len] + n) % 26;

----------------------------------------------------------------

源码：

public class Main {
    public static void main(String[] args) {
        int[] pow10 = {1, 10, 22, 12, 16};   // 第 5 步的表
        int rem = 0;                          // 第 2 步：只存余数
        int ans = 0;

        for (int n = 1; n <= 2026; n++) {
            int len = String.valueOf(n).length();      // 第 3 步：n 的位数
            rem = (rem * pow10[len] + n) % 26;         // 第 4 步：递推
            if (rem == 0) ans++;                       // 余 0 就是干饭日
        }
        
        System.out.println(ans);   // 76
    }
}
